# PromptCut

Плагин для Claude Code / Cowork: из промпта получается готовое видео. И набор
инструментов на все промежуточные шаги.

Говоришь «сделай вертикальное видео на 40 секунд про зонды „Вояджер“, спокойный
голос, с субтитрами» — Клод пишет раскадровку, озвучивает текст, генерирует или
ищет картинку под каждую фразу, оживляет их движением камеры, подкладывает музыку
с приглушением под голос, прожигает субтитры и рендерит mp4. Если хочется довести
руками — он вместо рендера собирает проект CapCut, где все клипы, субтитры и
эффекты уже стоят на таймлайне.

Это не один жёсткий пайплайн. Это ~30 маленьких команд. «Убери паузы из записи»,
«переделай это горизонтальное видео в вертикальное», «подложи музыку на −21 дБ с
ducking», «озвучь абзац» — каждое это одна команда, и Клод сам выбирает какая.

## Установка

From a local clone:

```
/plugin marketplace add C:\path\to\promptcut
/plugin install promptcut@promptcut
```

From GitHub, once you have pushed it:

```
/plugin marketplace add <your-github-user>/promptcut
/plugin install promptcut@promptcut
```

Потом в Клоде: `/promptcut:setup` — он проверит чего не хватает и скажет что
сделать. Коротко:

```
winget install Gyan.FFmpeg          # Windows
setx OPENROUTER_API_KEY sk-or-...   # для генерации картинок и озвучки
pip install pycapcut edge-tts pillow yt-dlp   # опционально: CapCut, голоса, выноски, веб-медиа
```

Обязательны только Python 3.10+ и ffmpeg. Всё остальное добавляет возможности.

## Что умеет

**Видео по промпту.** Всё описывается в `plan.json`: на каждый кадр — фраза для
озвучки, промпт картинки, движение, склейка, звук, титр. Флаг `--fake` делает
бесплатный прогон с заглушками — видно тайминг и разбивку субтитров ещё до того,
как что-то оплачено. Медиа кэшируется по хэшу, поэтому правка одной фразы не
заставит платить за остальные девять.

**Голос.** OpenRouter TTS или бесплатные голоса Microsoft Edge через `edge-tts`
(включая нормальные русские). Длина кадра берётся из реальной длины аудио, так
что картинка никогда не режет фразу на середине.

**Картинки.** Генерация через OpenRouter (Seedream, gpt-image — что доступно
твоему ключу), правка и склейка твоих фото промптом (`image-edit`) или стоки:
Pexels, Unsplash, Pixabay по бесплатному ключу; Openverse, Wikimedia Commons и
archive.org вообще без ключа. Музыка и звуки — Freesound, Jamendo, archive.org,
Openverse, а `media-dl` (yt-dlp) ищет по всему вебу и качает любой ролик — хоть
целиком, хоть нужные 2.5 секунды.

**Монтаж.** Обрезка, склейка с кроссфейдами, наложение логотипов и картинки в
картинке, титры, прожиг субтитров, музыка с ducking, скорость с сохранением
тональности, переделка в 9:16 с размытыми полями, вырезание паузы из говорящей
головы, детект склеек, кадры-превью, нормализация громкости до −16 LUFS.

**Выноски и карточки.** `annotate` рисует кружки, стрелки, рамки и подписи на
фото или прямо на видео — с таймингом и миганием. `kenburns --focus` плавно
въезжает в нужную точку кадра. `card` рендерит точную типографику (генеративные
модели коверкают текст): нумерация букв, подсветка подстроки, разделители
морфем — кадр «вот пруф на экране».

**Глаза и уши.** Клод не умеет проигрывать медиа, поэтому у тулбокса есть
органы чувств: `frames` собирает контактный лист кадров с таймкодами,
`waveform` рисует волну, спектрограмму и громкость, а `ask` отправляет картинку
или mp3 любой мультимодальной модели OpenRouter — «что за трек, где дроп?» — до
того, как хоть цент ляжет на таймлайн.

**CapCut.** Пишет настоящий проект: несколько дорожек видео, аудио, текста,
эффектов и фильтров, переходы (их 1137), эффекты сцены (1583), фильтры (454),
анимации входа и выхода, маски, кейфреймы на позицию, масштаб, поворот,
прозрачность и громкость, оформленный текст с анимацией и субтитры из SRT.
Названия эффектов ищутся командой, а не выдумываются.

## Как это разделено

Клод решает: какие кадры, что на картинке, сколько фраза должна дышать, какая
команда подходит под просьбу. Python делает детерминированное: запросы к API,
фильтры ffmpeg, арифметику таймингов, формат черновика CapCut. Каждая команда
печатает JSON в stdout и логи в stderr, поэтому Клод их спокойно связывает.

Про тайминг стоит знать одно: длина кадра — это длина озвучки плюс `lead` и
`tail`, а клип рендерится длиной `duration + transition`, чтобы `xfade` съел
перехлёст и звук не уехал относительно картинки. Даже после десяти кроссфейдов
голос стоит ровно там, где показывают субтитры.

## Деньги

Генерация картинок и OpenRouter TTS платные, за вызов. Каждый вызов пишется в
`~/.promptcut/spend.jsonl`, `promptcut spend` считает сумму, `build` показывает
расход за прогон. Стоки, голоса Edge и весь монтаж — бесплатно.

## Ограничения

- CapCut сам рендерит свои экспорты: PromptCut пишет проект, но кнопку «Экспорт»
  не нажимает. Чтобы увидеть новый черновик, CapCut надо перезапустить, и нельзя
  писать в открытый проект.
- Переходы CapCut отъедают время у обоих соседних клипов, из-за чего видео
  уезжает относительно отдельной дорожки озвучки. `capcut-from-plan` их не
  добавляет, пока не передашь `--transitions`.
- Кроп в 9:16 идёт по центру, слежения за лицом нет.
- Поиск по стокам требует интернета: за строгим allowlist провайдеры просто не
  ответят.

Полное описание команд — в англоязычном [README](README.md) и в скиллах
`skills/video-toolbox` и `skills/capcut-draft`.
